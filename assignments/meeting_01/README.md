# Meeting 1 — Build an Agent Loop

Implement a minimal reasoning–action–observation loop over supplied local text
documents. Do not use an agent framework for the core loop.

Your first checkpoint is a bounded loop that can request one read-only tool,
observe its result, and terminate with a traceable answer. Complete error
handling, tests, evaluation cases, and the engineering note before Meeting 2.

Detailed acceptance criteria will be published with the meeting materials.
